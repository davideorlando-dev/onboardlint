# Security Policy

## Supported versions

Security fixes are currently provided for the latest released version on the default branch. This policy may change as the project matures.

## Reporting a vulnerability

Please do not report vulnerabilities in public issues. Use GitHub's **Report a vulnerability** feature on this repository, when available, to contact the maintainer privately. Include the affected version, impact, and a minimal reproduction where possible.

Please allow maintainers reasonable time to investigate and coordinate a fix before public disclosure. Do not include real secrets, personal data, or third-party data in reports.

## Scope

OnboardLint reads local repository metadata and selected text files. It does not execute the code it audits or make network requests. Security reports about the package, CLI, or report-writing behaviour are in scope.
