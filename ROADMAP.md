# Roadmap

This roadmap is exploratory. Priorities depend on real maintainer feedback and evidence from public repositories.

## Near term

- Add fixture repositories for Python, JavaScript/TypeScript, Go, and Rust.
- Improve test-runner detection and compare documented commands against CI workflows.
- Add GitHub Actions integration with a concise job summary.
- Publish the JSON report schema and a compatibility policy.
- Gather opt-in feedback from maintainers about false positives and missing checks.

## Later

- Add checks for release notes, versioning policy, support channels, and issue triage guidance.
- Support repository-specific configuration without making the default audit opaque.
- Provide a machine-readable baseline so teams can prevent regressions without requiring a perfect score immediately.

## Non-goals

- Ranking repositories by popularity or judging maintainer productivity.
- Requiring a specific hosting platform, CI vendor, or project governance model.
- Executing repository code, installing dependencies, or uploading repository content.
- Treating a numeric score as proof that a project is safe, healthy, inclusive, or well-maintained.
